# Computer Vision with Arduino UNO Q and Edge Impulse

Join an interactive and practical workshop to explore Computer Vision at the edge using Edge Impulse and Arduino UNO Q. You will learn how to collect data and train an object detection model to filter events in real time. No prior experience in Machine Learning is required. Bring your laptop, your mobile phone and your curiosity! By the end of the workshop, participants will have built a complete object detection system running locally on the Arduino UNO Q.

## Objectives

* Collect and label data with a mobile phone to train an object detection model.
* Train and optimize a computer vision model with Edge Impulse.
* Deploy the model on Arduino UNO Q and run real-time inference.
* Understand the concept of model cascading and how to apply it to improve efficiency.
* Gain the foundations to create your own Edge AI projects with computer vision, sound or temporal data.

## Requirements

* Participants must bring a laptop and mobile phone for data collection.
* We recommend having Arduino App Lab software installed.
* All necessary hardware will be provided: Arduino UNO Q, camera, USB hub, cables, etc., which must be returned at the end of the session.
* At the end of the workshop, guides, code and models will be provided so participants can continue experimenting at home.
