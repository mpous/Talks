# Construyendo robots con ROS 2 y Arduino VENTUNO Q

Find here the ROS2 deployment instructions here: https://gist.github.com/mpous/7cd6d7f52ea0d2b78d625d26c98fbbf8

## Objectives

* Collect and label data with a mobile phone to train an object detection model.
* Train and optimize a computer vision model with Edge Impulse.
* Deploy the model on Arduino VENTUNO Q as a ROS2 node.
* See how all the topics are exposed and finally check the ROS2 bridge node between the MCU and the NPU (during the workshop the bridge node was not public yet)

## Requirements

* Participants must bring a laptop and mobile phone for data collection.
* We recommend having Arduino App Lab software installed.
* All necessary hardware will be provided: Arduino VENTUNO Q, camera, USB hub, cables, etc., which must be returned at the end of the session.
* At the end of the workshop, guides, code and models will be provided so participants can continue experimenting at home.
